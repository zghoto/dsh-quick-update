feat: the mark opens the same bubble the page's own tooltips show

The mark used the browser's own title, which shows a plain rectangle after
a moment and looks nothing like the rest of the page. The page's tooltips
are a React component, which injected DOM cannot use, but the bubble they
render is a fixed-positioned element on the document body whose whole look
comes from the theme tokens the page already sets. The same bubble is built
here, with the same tokens, the same shape and the same placement, so it
reads as part of the page rather than as a second kind of hint.

The mark also carries the hint as its accessible name, so it is reachable
by the keyboard: it opens the bubble on focus and closes it on blur.

The field is narrower now — just wide enough for two digits — and the
spacing around it is tighter.
